# Angular Demo

Angular-backed demo for the initial Gethen adapter slice.

Run `pnpm demo`, then open `http://127.0.0.1:4173/apps/angular-demo/`.
The demo source is split across `index.html`, `styles.css`, `src/main.html`, and `src/main.ts`.
It bootstraps Angular in the browser and mounts the built `@thefoolspath/gethen-angular` adapter package.
