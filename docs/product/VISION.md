# Product Vision

Last reviewed: 2026-08-04.

Gethen aims to become an open-source, MIT-licensed data-grid ecosystem for web applications that need spreadsheet-like interaction with large datasets.

## Target Users

- Application developers building internal tools, admin screens, analytics views, and data-heavy web apps.
- Teams that need advanced grid capabilities without enterprise-license lock-in.
- Future backend developers who want safe query translation into server-side data sources.

## Product Direction

The long-term product direction includes:

- typed column definitions
- virtualized rendering
- keyboard navigation
- cell selection
- cell editing
- client-side and server-side DataSource support
- sorting and filtering
- lazy loading and pagination
- future formulas, grouping, aggregation, and pivot tables
- React and Angular integration
- future .NET companion packages

These are targets, not implemented capabilities.

## Differentiator

Gethen should compete through permissive licensing, transparent performance budgets, framework-neutral design, and a protocol that can support both frontend and backend data operations safely.
