# Research Sources

Last reviewed: 2026-08-07.

Use this folder to track source material used during research.

## Structure

- `pdf/`: PDFs or other original files when they are allowed to be stored in the repository.
- `converted/`: Markdown converted from PDFs or large files, normally using Microsoft `markitdown`.
- `metadata/`: citation, license, access date, URL, local filename, conversion command, and redistribution notes.

## Rules

- Prefer official specifications, maintainer documentation, standards, peer-reviewed papers, and primary project sources.
- For PDFs, papers, large files, or token-heavy sources, convert to Markdown before deep reading when `markitdown` is available.
- Do not commit restricted PDFs or full converted text when redistribution is not allowed.
- If a source cannot be redistributed, keep metadata, citation, access date, and concise notes only.
- Record conversion limitations, extraction errors, missing figures, and tables that need manual review.
